## 已知限制 / 后续可做

- **单实例假设**：限流恢复与序列排期用的是进程内定时器，重启后会重新挂上，但多实例部署时会各挂一份；重启时把 `sending` 行一律当作崩溃遗留处理，同样假设只有一个实例在发。agent run 的"同群至多一个 running"靠数据库唯一索引保证，多实例下也成立。
- **WS 广播**：`ws_events.seq` 是 BIGSERIAL，并发事务提交顺序可能和 seq 顺序不一致，轮询广播可能跳过一个晚提交的小 seq。前端重连时带 `sinceSeq` 能补回来，但在线期间可能漏推。
- **按钮语义**：账号页"标记离线"对应 `→ disconnected`、"释放账号"对应 `→ idle`。依据是 A1"到期时账号已不是 `rate_limited`（例如已被操作员标记离线）"——`rate_limited` 唯一的离线出边是 `disconnected`；`idle` 是初始的未占用状态，对应"释放"。
